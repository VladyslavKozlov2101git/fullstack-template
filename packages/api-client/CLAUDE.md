# packages/@repo/api-client — generated

`src/schema.d.ts` is generated by `openapi-typescript` from the API's OpenAPI spec. **Never
hand-edit it.**

Regenerate: start the API (`pnpm --filter api dev`), then `pnpm --filter @repo/api-client generate`.

`src/index.ts` is the only hand-written file here: a `createApiClient` factory plus re-exported
types. Apps create their own instance so they can attach middleware — see
`apps/web/src/services/api.ts`.

Don't add wrappers, retry layers or per-endpoint helpers here. Endpoint types come from `paths`:

```ts
type Users = paths["/users"]["get"]["responses"][200]["content"]["application/json"];
```
