# packages/api-client — generated

`src/schema.d.ts` is generated by `openapi-typescript` from the API's OpenAPI spec. **Never hand-edit it.**

Regenerate: start the API (`pnpm --filter api dev`), then `pnpm --filter @app/api-client generate`.

`src/index.ts` is the only hand-written file here — a `createClient` call and re-exported types. If you are about to add a wrapper, a retry layer or per-endpoint helpers, don't: put that in the calling app, or in the API.
