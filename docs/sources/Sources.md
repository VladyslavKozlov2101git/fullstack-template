# sources

Notes on primary sources, one page per source, created from [[Source|99-Templates/Source]].
Originals go in `sources/raw/YYYY-MM-DD/` and are never edited.

Every page here links to the pages it affects, and those pages link back in their Sources section.
That is what makes a fact traceable: any statement in this vault should be followable to the source
it came from, and from the source to everything it touched.
