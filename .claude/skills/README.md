# skills

Project skills — one folder per skill, each with a `SKILL.md`:

```
.claude/skills/<name>/SKILL.md
---
name: <name>
description: <when Claude should load this — triggers, not a summary>
---
```

Empty on purpose. Add one when a workflow in this repo gets repeated often enough to be worth
writing down; don't pre-write skills for workflows that don't exist yet.
